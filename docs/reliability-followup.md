## 實作結果

- 績效 API 新增 `missing_sessions`；股票回放在缺少 ETF 基準時為 `partial`，基準報酬、波動度及 Beta 為 `null`。若持股本身含 ETF，整體回放不可用，配置仍獨立計算。未知平日不當成休市，沿用本機交易日證據判斷。
- 零股快照需要明確數字與有效台股代號。自動同步在同一帳本鎖中確認檔案版本，成功才記錄完成；失敗保留原帳本。回復上次取代前版本會停止自動同步，避免剛回復又被覆寫。復原版本使用既有裝置備份允許清單保存。
- 研究保存原候選的 `model_key` 與日期；研究歷史呈現當時選股、持股及來源提醒，連到原候選快照與既有事後追蹤頁。個股研究清單可開啟指定紀錄，即使該紀錄不在最近 100 筆內。舊紀錄缺來源時不補成目前候選或零持股。
- 持股及提醒沿用個股頁的原有元件；跳轉會展開並定位對應區塊。籌碼追蹤可展開已凍結名單、存檔／進場日期及個股報酬，回到個股與研究歷史。
- 籌碼追蹤也移除僅避開 1、7 月的猜測。完整股票樣本仍計算自身報酬與上漲比例；ETF 基準、超額報酬及勝過基準比例維持不可用。
- 移除 `strategyDraft`、`strategyModify`、`strategyBuilderDraft`、`strategyRules`、`strategyBacktestLast` 定義；未刪除瀏覽器內既有 key 或內容。

## 效能量測

固定合成資料，每天 40 檔、1／5 日持有期間，價格每日遞增，無公司行動。使用記憶體 daily store 與固定平日行事曆，各規模連續執行 3 次 `ChipRankingTracker.report()`，取中位數；改前為 `07ae049`，改後為本次工作區版本。

| 累積排行天數 | 改前（秒） | 改後（秒） |
| --- | ---: | ---: |
| 30 | 6.331 | 0.025 |
| 120 | 24.006 | 0.076 |
| 252 | 45.777 | 0.175 |

優化為每次報告建立一次 `(symbol, date)` 價格索引；沒有事件時直接驗證價格並計算，有事件仍呼叫唯一復權實作。沒有新增長期快取，價格修正或除權息涵蓋改變會在下一次報告立即反映。這是計算熱點量測，不含真實磁碟、官方資料請求與本機交易日證據讀取；不能視為整頁載入時間。改後另移除了未驗證基準計算，因此比較反映本次完整修改，非單一最佳化的獨立效果。
