## 實作結果

- 績效 API 新增 `missing_sessions`；股票回放在缺少 ETF 基準時為 `partial`，基準報酬、波動度及 Beta 為 `null`。若持股本身含 ETF，整體回放不可用，配置仍獨立計算。未知平日不當成休市，沿用本機交易日證據判斷。

優化為每次報告建立一次 `(symbol, date)` 價格索引；沒有事件時直接驗證價格並計算，有事件仍呼叫唯一復權實作。沒有新增長期快取，價格修正或除權息涵蓋改變會在下一次報告立即反映。這是計算熱點量測，不含真實磁碟、官方資料請求與本機交易日證據讀取；不能視為整頁載入時間。改後另移除了未驗證基準計算，因此比較反映本次完整修改，非單一最佳化的獨立效果。
