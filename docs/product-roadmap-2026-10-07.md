# 台股看板產品規劃（2026-10-07，修正版）

結論：以既有「每日承接雷達」為唯一主畫面，依序做三步：先驗收本地 LLM 與通知，再讓雷達直接看懂並一鍵監控，最後盤後自動產生 AI 說明。不另建分析表、通知框架或績效系統。

基準：`main` `f3bc45b`（Auto Watch v1 #91 合併後）。本文件取代 Codex 同日初版規劃。

## 與初版的差異

| 初版 | 修正 | 原因 |
| --- | --- | --- |
| P1-A 新手入口整合先做，P1-B 本地 LLM 驗收第二 | 先驗收本地 LLM 與通知 | 所有 AI 功能都依賴它；模型速度決定每日可生成檔數 |

| README 定位改寫為獨立項 | 併入第 2 步 | 只是文字 |

## 第 1 步：本地 LLM 與提醒實測（已完成）

- AI 設定以「設定檔」切換電腦：家裡 `家裡 LM Studio (5080)` → `http://127.0.0.1:1234/v1`、`qwen3.6-35b-a3b`。辦公室另建一組設定檔，切換即可，不改程式。
- 本機 LLM（127.0.0.1 / localhost）請求一律關閉思考模式：LM Studio 用 `reasoning_effort: "none"`，llama.cpp 用 `chat_template_kwargs.enable_thinking=false`。不關閉時 Qwen 會把輸出額度耗在思考，Research 62 秒後截斷失敗；關閉後 9 秒成功。
- 修正既有 bug：Advice 呼叫 `generate_structured_ai_text` 缺少必要參數 `truncated_retry_message`，main 上任何模型的個股 AI 建議都會失敗（測試因 mock `_call_provider` 未發現）。已補參數與走真實路徑的測試。
- 實測（2026-10-07 晚間，當日日線尚未更新，三檔均正確判為不可買）：

- 限制：後端未執行時不會盯盤、不會在 16:30 更新資料（本次實測當日資料即因此缺漏）。

## 第 2 步：雷達直接看懂、一鍵監控

- 雷達每列加「AI 說明」：沿用既有 Advice（帶 `selection_evidence`），顯示白話理由、主要風險、失效條件。
- 價位只顯示新手計畫一套；強度不是上漲機率，AI 不參與排名。
- 確認每列可一鍵加入自選（＝ Auto Watch 自動監控）。
- README「不推薦個股」等舊定位改為符合現況的 Research / Advice 邊界說明。
- 驗收：從雷達一路完成「看候選 → 看懂理由 → 開監控」不換頁；空名單、缺資料、AI 失敗各有下一步提示。

## 第 3 步：盤後自動 AI 說明

- 設定加開關，預設關閉。開啟後於盤後資料就緒時，為雷達前 N 檔生成 AI 說明（預設 5；依第 1 步速度，5080 約 1–2 分鐘）。
- 以（股票、資料日期、計畫版本）快取，同版本不重複生成；失敗標示失敗，不冒充成功。
- 驗收：重啟後可讀前次結果；資料未就緒、LLM 逾時各自顯示正確狀態。
