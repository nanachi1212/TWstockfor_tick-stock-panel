# 功能總覽

Nanachi 的台股監控看板以台灣上市、上櫃股票為範圍，提供市場觀察、客觀篩選、自選追蹤、多股比較與條件監控。逐頁操作請見 [操作說明書](../操作說明書.md)，設定與部署請見 [設定說明](./configuration.md)及[部署說明](./deployment.md)。

## 看板

- 顯示今日漲跌家數、市場強弱、產業強弱與台股資料狀態。
- 彙整自選股動態與最近的監控觸發記錄。
- 缺少或尚未更新的資料會顯示狀態，不以數值零代替。

## 台股選股

- 使用 TWSE、TPEx 公開資料建立全市場量化統計快照。
- 提供產業輪動、客觀異常訊號、常用篩選，以及技術面與法人籌碼條件。
- AI 自然語言解析只把文字轉成可預覽的篩選條件，不直接推薦股票，也不自動執行投資決策。

## 自選股與多股比較

- 自選股支援分組、表格或卡片檢視、自訂欄位、迷你日 K 與分時資料。
- 多股比較並列報酬率、法人買賣超、本益比與異常訊號等客觀資料。
- AI 比較是選配功能，只有使用者手動觸發時才會呼叫已設定的模型。

## 個股頁面

- 顯示歷史日 K、成交量、即時報價與五檔盤口。
- 顯示三大法人、融資融券、券資比與核心籌碼滾動因子。
- 漲跌幅限制依標的與交易日規則判定；無漲跌幅限制或資料不足時明確標示不可用。

## 監控中心

- 支援價格、漲跌幅、成交量與接近漲跌停等規則。
- 支援冷卻時間、遲滯防抖、觸發記錄及 LINE／Telegram 推播。
- 推播渠道各自設定與測試；未設定外部渠道時，本機監控與記錄仍可使用。

## 資料與擴充

- 預設資料來源為 TWSE／TPEx 官方公開資料，不需要付費行情 API Key。
- 歷史日 K 可由 GitHub Release 資料包匯入，再補齊到最近交易日。
- 資料在本機以 Parquet／DuckDB 儲存；資料來源可依既有 provider 與插件契約擴充。
- 自訂資料來源請見 [自訂資料來源](./custom-data-source.md)與[插件開發](./plugin-development.md)。

本產品不提供因子挖掘、A 股連板分析、舊式策略回測平台或自動下單功能。
